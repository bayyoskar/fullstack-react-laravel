# 📘 API Specification - User Management System (Laravel x React.js)

## 🧩 Overview
API ini digunakan untuk menghubungkan backend Laravel dengan frontend React.js.
Sistem ini memiliki tiga peran pengguna:
- **User** → bisa login, view/edit profil.
- **Admin** → bisa kelola user (create, edit, delete).
- **Super Admin** → bisa kelola admin, lihat dashboard dan activity log.
